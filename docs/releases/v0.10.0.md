# Agenvyl v0.10.0

This release makes conversation routing the standard room experience, adds
safe Plan/Work session handoffs, and brings live Antigravity output and tool
activity into the timeline. It also improves retries, continuation context,
streaming reasoning, and recovery from harness failures.

## Highlights

- Conversation routing is now enabled by default. **Auto**, **Room context**,
  and **Agent session** select whether a message starts from canonical room
  history or continues a retained native session. The first message in a room
  with one agent is routed to that agent automatically.
- Switching between Plan and Work no longer risks continuing a session under
  stale permissions. Each message snapshots its workflow mode; a cross-mode
  follow-up starts a fresh native session after the active run becomes
  terminal and is labelled **New session · mode changed**.
- The composer adds a one-shot **Start fresh** command for deliberately
  beginning a new agent session without changing the room's default route.
- **Apply now** instructions that reached Applied are included when retrying a
  failed or cancelled run and are labelled **Included in retry**. Failed and
  pending instructions are not replayed.
- Agent-session continuations can carry attachments. Their bounded canonical
  history is now assembled by completed conversation rounds, keeping related
  user messages, applied instructions, agent output, and failure context
  together before connector transport.
- Failed agent output is preserved and exposed to recovery turns instead of
  disappearing from context. Recovered responses remain visible, and
  Antigravity handles tool failures without discarding the surrounding answer.
- Antigravity now streams assistant text and tool lifecycle from AGY's
  structured protocol, records terminal usage, and surfaces supported
  communication thoughts as reasoning.
- Streaming reasoning is smoother and easier to follow: activity stays pinned
  to the latest snapshot before paint, updates avoid redundant renders, and
  the indicator better reflects active output.

## Upgrade notes

Database migrations 036 and 037 add persisted workflow-handoff snapshots,
transition reasons, and the `started_fresh` delivery state. They preserve
existing rooms, messages, runs, follow-ups, Workspace repositories, and preview
artifacts.

Conversation routing no longer requires
`AGENVYL_EXPERIMENT_CONVERSATION_ROUTING`; deployments may remove that setting.
Each existing run keeps its immutable execution profile, while new messages use
the room mode selected when they are sent.

Native continuation and retry do not roll back commands, Workspace changes,
elapsed time, or external side effects from earlier turns. A Plan/Work handoff
invalidates the old retained continuation handle before the new session starts.

## Supported harnesses

- Codex CLI
- Claude Code CLI *(experimental)*
- OpenCode
- Antigravity / AGY `1.1.8` or newer
- Hermes
- Cursor CLI *(experimental)*

Capabilities remain harness-specific. Active intervention is available for
Codex and OpenCode; completed-response continuation is available for Codex,
OpenCode, and AGY. Antigravity streams supported output but its headless
protocol does not expose approval or clarification round-trips. Plan
enforcement and permission boundaries are not an operating-system sandbox.

## Supported platforms and installation

Portable packages support Windows 10/11 x64, Linux x64/arm64, and macOS on
Intel and Apple silicon. Releases remain unsigned Technical Preview builds for
a trusted single-user computer. Core, Connector, PostgreSQL, and the preview
server bind to loopback by default, but connected harnesses and rendered app
previews can retain their own network capabilities.

Install the latest stable build with the commands in the
[installation guide](../user-guide/installation.md), or download a platform
archive and verify `SHA256SUMS` from the same GitHub release.
