# Agenvyl v0.6.0

This release makes planning a persistent room-level workflow, improves the
conversation UI, strengthens managed OpenCode lifecycle handling, and expands
the built-in operating documentation.

## What's new

- A persistent **Plan** mode for each room. Every responder in a message round
  receives the same read-only intent, retries preserve the original mode, and
  switching back to Work is explicit.
- A redesigned message composer with a compact single-line starting state,
  clearer responder status, an accessible add menu for attachments and the
  Workspace, and a dedicated Plan toggle.
- A collapsible desktop sidebar whose preference is remembered in the browser,
  with compact access to room creation, search, agents, projects, and profile
  controls.
- Optional project selection directly in the new-room dialog through **Add
  project**.
- A complete `agenvyl help` reference for the command line and terminal control
  center, plus a user guide for Connector YAML configuration.
- Managed OpenCode servers are now owned by the Connector process, cleaned up
  more reliably on shutdown, and contained in a Windows Job Object where the
  platform permits it.
- OpenCode external-directory requests can safely cover nested allowed paths
  under one requested boundary.

## Fixes and refinements

- Human messages without an agent mention remain part of later conversation
  history even though they start no run.
- User messages have clearer visual separation and improved readability.
- CI performs the fast local checks separately from portable build validation,
  reducing duplicated work while retaining release gates.

## Upgrade notes

Database migrations run automatically at Core startup. This release adds the
room workflow-mode migration and initializes existing rooms in Work mode. Back
up PostgreSQL and the workspace root as one recovery point before upgrading a
persistent installation.

Plan mode is guidance plus the strongest native read-only controls exposed by
each harness; it is not an operating-system sandbox. Harnesses marked
**Instruction-only** may still write with the permissions of the Agenvyl
process.

Existing `connector.yaml` files remain valid. Operators who manage OpenCode or
allow external directories should review the expanded
[Connector configuration guide](../user-guide/connector-configuration.md).

## Platforms and harnesses

Self-contained archives are provided for Linux x64/arm64, macOS x64/arm64, and
Windows x64. They bundle Node.js 22 and PostgreSQL 17.10.

The Connector supports Codex CLI, Claude Code, OpenCode, Antigravity/AGY,
Hermes, and experimental Cursor CLI. Harness capabilities differ; see the
[capability matrix](../harnesses/capabilities.md) before choosing an agent.

## Trust boundary

This release is unsigned and intended for a trusted single-operator
workstation. It has no service/autostart, automatic update, tray application,
telemetry, or multi-user authorization layer. Room workspaces and every
explicitly permitted external directory are trusted agent-accessible locations,
not security sandboxes. A selected local project is contextual guidance only;
the harness permission profile remains authoritative. Review the
[trust guide](../user-guide/trust-and-security.md) before installation.

## Install

Linux or macOS:

```bash
curl -fsSL https://github.com/riffi/agenvyl/releases/download/v0.6.0/install.sh |
  sh -s -- --version 0.6.0
```

Windows PowerShell:

```powershell
$env:AGENVYL_VERSION = '0.6.0'
irm https://github.com/riffi/agenvyl/releases/download/v0.6.0/install.ps1 | iex
```
