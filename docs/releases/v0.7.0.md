# Agenvyl v0.7.0

This release adds captured static app builds with current and historical
previews, introduces cooperative redirect for active Codex runs, and makes run
recovery and workspace finalization more resilient.

## What's new

- Agent runs can retain static app output as an immutable build tied to the
  exact response and result snapshot.
- Responses expose **Open this build** when `dist/index.html`,
  `build/index.html`, `out/index.html`, or a supported plain-static entry point
  is captured.
- The Workspace has separate **App** and **Files** views, a build-history
  selector, current and historical states, agent/time/run/publication metadata,
  and detection of equivalent consecutive builds.
- A preview is current only while its conflict-free published source still
  matches the room. Later source changes produce an explicit outdated gate
  instead of silently showing a stale app.
- Generated output, dependencies, caches, test artifacts, secrets, and captured
  `.gitignore` matches stay out of normal source publication and response file
  lists while remaining available inside the immutable build snapshot.
- Active Codex runs accept a cooperative redirect. Agenvyl interrupts the
  current turn and continues in the same thread, run, and workspace with new
  guidance.

See the [app build user guide](../user-guide/app-builds.md) and
[architecture reference](../architecture/app-builds.md).

## Reliability and lifecycle

- Redirect state survives same-Connector-epoch Core recovery. Stop takes
  precedence, while Connector restart remains fail-closed.
- Workspace finalization resumes abandoned captures and publication after a
  restart. Complete snapshots from failed or cancelled runs remain available
  for inspection and explicit application where allowed.
- Workspace worktree cleanup has durable retry and quarantine behavior.
- Optional warm slots and stat-cache modes reduce repeated materialization and
  hashing while retaining manifest verification gates.
- Supervisor stop, restart, and cleanup coordination avoids stale state writes
  and process-lifecycle races.

## Fixes and refinements

- Terminal runs present finalization and captured-file status more accurately.
- OpenCode write access remains anchored to the managed Agenvyl workspace when
  external directories are allowed.
- The Windows portable bundle resolves the npm launcher correctly.
- Antigravity/AGY bounds inline prompts to the Windows command-line limit and
  falls back safely for larger context.
- Workspace App/Files navigation clears stale file selection while preserving
  an explicitly selected historical build.

## Upgrade notes

Database migrations run automatically at Core startup. This release adds run
artifact visibility and classifies existing generated, cache, and secret-like
artifacts as hidden. Back up PostgreSQL and the workspace root as one recovery
point before upgrading a persistent installation.

Existing rooms and captured source versions remain compatible. Generated
output is retained in immutable run snapshots but excluded from subsequent
automatic source publication according to the new artifact policy.

Redirect is not a rollback. Commands may finish before an interrupt is
observed, and filesystem or external side effects that already happened remain
in place.

## Platforms and harnesses

Self-contained archives are provided for Linux x64/arm64, macOS x64/arm64, and
Windows x64. They bundle Node.js 22 and PostgreSQL 17.10.

The Connector supports Codex CLI, Claude Code, OpenCode, Antigravity/AGY,
Hermes, and experimental Cursor CLI. Redirect is currently Codex-only. Harness
capabilities differ; see the [capability matrix](../harnesses/capabilities.md)
before choosing an agent.

## Trust boundary

This release is unsigned and intended for a trusted single-operator
workstation. It has no service/autostart, automatic update, tray application,
telemetry, or multi-user authorization layer. Room workspaces and every
explicitly permitted external directory are trusted agent-accessible locations,
not security sandboxes.

Build previews execute captured frontend code in a sandboxed iframe on a
separate local preview origin. They may make network requests under the preview
policy; origin isolation does not make untrusted application code harmless.
Review the [trust guide](../user-guide/trust-and-security.md) before
installation or opening unfamiliar generated output.

## Install

Linux or macOS:

```bash
curl -fsSL https://github.com/riffi/agenvyl/releases/download/v0.7.0/install.sh |
  sh -s -- --version 0.7.0
```

Windows PowerShell:

```powershell
$env:AGENVYL_VERSION = '0.7.0'
irm https://github.com/riffi/agenvyl/releases/download/v0.7.0/install.ps1 | iex
```
