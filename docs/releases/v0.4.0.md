# Agenvyl v0.4.0

This release makes harness configuration safer and easier to manage, improves
interactive agent runs, and hardens Connector execution across configuration
changes and interrupted event streams.

## What's new

- A redesigned harness settings flow with a compact instance list, an explicit
  add drawer, inline editing, and a safer preview before setup changes are
  applied.
- Per-agent permission profiles for Codex and AGY. Codex Full access and AGY
  Accept edits each require an explicit warning confirmation, while Agenvyl's
  Plan workflow continues to force read-only execution.
- Native Codex MCP elicitation support and parallel approval handling, so runs
  can ask structured questions and keep multiple tool requests distinct.
- Clear failed-tool and failed-run states in the timeline, with preserved agent
  message boundaries and more resilient event streaming.
- Generation-aware Connector reconfiguration. Existing runs stay pinned to the
  adapter generation that accepted them while new runs use the latest saved
  configuration.
- Stronger execution recovery and lifecycle handling across Core or Connector
  restarts, including durable generation metadata and safer cleanup.
- A fitted workspace image viewer with zoom controls for inspecting generated
  images without leaving the room.
- Reasoning effort now resets when a room switches to a model that does not
  support the previously selected value.

## Upgrade notes

Database migrations run automatically at Core startup. Back up PostgreSQL and
the workspace root as one recovery point before upgrading a persistent
installation.

Codex Full access is now selected per agent. Remove the obsolete
`allowDangerFullAccess` field from existing Connector instance configuration.

AGY permissions are also selected per agent. Remove the obsolete
connector-level `permissionMode` field; existing and new AGY agents default to
Plan only until Accept edits is explicitly confirmed.

## Platforms and harnesses

Self-contained archives are provided for Linux x64/arm64, macOS x64/arm64, and
Windows x64. They bundle Node.js 22 and PostgreSQL 17.10.

The Connector supports Codex CLI, Claude Code, OpenCode, Antigravity/AGY, and
Hermes. Harness capabilities differ; see the
[capability matrix](../harnesses/capabilities.md) before choosing an agent.

## Trust boundary

This release is unsigned and intended for a trusted single-operator
workstation. It has no service/autostart, automatic update, tray application,
telemetry, or multi-user authorization layer. A room workspace and every
explicit OpenCode external-directory root are trusted agent-accessible
locations, not security sandboxes. Rendered HTML and SVG are isolated, but may
execute document content within the preview boundary. Review the
[trust guide](../user-guide/trust-and-security.md) before installation.

## Install

Linux or macOS:

```bash
curl -fsSL https://github.com/riffi/agenvyl/releases/download/v0.4.0/install.sh |
  sh -s -- --version 0.4.0
```

Windows PowerShell:

```powershell
$env:AGENVYL_VERSION = '0.4.0'
irm https://github.com/riffi/agenvyl/releases/download/v0.4.0/install.ps1 | iex
```
