# Agenvyl v0.5.0

This release adds reusable local-project context, introduces an experimental
Cursor CLI integration, and makes first-run workspace setup clearer and more
flexible.

## What's new

- A local project catalog for registering named folders once and recommending
  them to agents when creating or updating a room.
- Immutable project snapshots on runs and retries. Agenvyl records the project
  name, canonical path, and availability used by each attempt while keeping the
  isolated room workspace as the execution working directory.
- Native folder pickers for project registration on Windows and macOS, with
  Zenity or KDialog support on Linux and manual absolute-path entry everywhere.
- Experimental Cursor CLI support with model discovery, native Plan mode,
  explicit Accept edits opt-in, streamed answers and tool activity,
  cancellation, concurrent runs, and replay within one Connector epoch.
- An editable workspace root during first-run setup, including a native folder
  picker and coordinated Core/Connector configuration.
- Clearer setup field guidance, handle validation, harness selection, empty
  states, and project-page layout.
- Broader Connector compatibility with terminal tool events and OpenCode
  external-directory requests emitted by Bash tools.
- Visible installer download progress on Linux and macOS.

## Upgrade notes

Database migrations run automatically at Core startup. Back up PostgreSQL and
the workspace root as one recovery point before upgrading a persistent
installation.

Existing installations keep their configured workspace root. The editable
workspace-root field is part of first-run setup and does not move existing room
files during an upgrade.

Local projects are optional. Registering or selecting one does not change a
run's working directory, extend a sandbox, or add an OpenCode external-directory
root. Configure access separately for each harness and permission profile.

## Platforms and harnesses

Self-contained archives are provided for Linux x64/arm64, macOS x64/arm64, and
Windows x64. They bundle Node.js 22 and PostgreSQL 17.10.

The Connector supports Codex CLI, Claude Code, OpenCode, Antigravity/AGY,
Hermes, and experimental Cursor CLI. Cursor CLI requires version `2026.01.16`
or newer and is supported when Connector and the workspace run in the same
macOS, Linux, or WSL environment. Harness capabilities differ; see the
[capability matrix](../harnesses/capabilities.md) before choosing an agent.

## Trust boundary

This release is unsigned and intended for a trusted single-operator
workstation. It has no service/autostart, automatic update, tray application,
telemetry, or multi-user authorization layer. Room workspaces and every
explicitly permitted external directory are trusted agent-accessible locations,
not security sandboxes. A selected local project is contextual guidance only;
the harness permission profile remains authoritative. Review the
[trust guide](../user-guide/trust-and-security.md) before installation.

## Install

Linux or macOS:

```bash
curl -fsSL https://github.com/riffi/agenvyl/releases/download/v0.5.0/install.sh |
  sh -s -- --version 0.5.0
```

Windows PowerShell:

```powershell
$env:AGENVYL_VERSION = '0.5.0'
irm https://github.com/riffi/agenvyl/releases/download/v0.5.0/install.ps1 | iex
```
